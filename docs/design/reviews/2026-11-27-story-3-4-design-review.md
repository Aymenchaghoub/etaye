## Design choices and verification boundary

- **User decision (UD-78).** The new Biologie tab is visible alongside the delivered record tabs, without I-07 or the document viewer. At narrow widths the tabs wrap and the table restacks with visible field labels. A source marker opens the exact labelled disclosure, then “Revenir au résultat” returns to the initiating marker. The render keeps the clinical frame in partial, empty and recovery states.
- **Proposal for design approval.** Keep the six table columns (Prélèvement, Analyse, Résultat, Unité, Intervalle fourni, Source) in fixed order. A supplied result date is named explicitly if the specimen date is unknown. A missing interval reads “Intervalle non fourni.” Source-supplied comments appear next to the associated row in words. Numeric data wraps only when needed, with the original decimal scale and comparator. The table remains the accessible reference for the point-only chart.
- **Verified observation.** Claire’s canonical results are preserved. The excerpt displayed for `SRC-A-003`/page 1 is an explicitly labelled synthetic proposal that includes both supplied intervals, which the existing runtime seed omits. The “Analyse A–E” proof rows, the correction and its times, the long data and the comparable two-point series are examples for design review. The default Claire specimen displays no chart because the current fixture does not establish comparable method, fasting and time context. This keeps the plotting constraint visible without adding unsupported facts to the existing fixture.
- **Verified distinction.** The gallery is a local, static document with prepared transitions. It illustrates keyboard, filter, date, source and retry behavior without live HTTP, persistence, a real clock or a working authorization policy. The full data-driven filter, pagination, temporal validation and failure behaviors remain planned under AT-012. The gallery is independent of contract and application changes.
- **To verify.** Clinical text remains synthetic. The authorized contract-first phase must resolve treatment of date-only filter boundaries, availability of exact analyte options, provenance additions and the exact fixture/lineage identifiers. The running interface must pass the AT-012-C evidence matrix, including appropriate zoom/reflow and real authorization checks.
