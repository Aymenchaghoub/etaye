## Objective and delivery boundary

A practitioner with current access to a practice-local record can read seeded laboratory results on S-12. Each result retains its original numeric or qualitative value, comparator, unit, supplied reference interval, dates and dated source. An absent interval reads “Intervalle non fourni.” A supplied interval describes one result in its reported context. It establishes no general range, diagnosis, treatment advice or inferred normality.
