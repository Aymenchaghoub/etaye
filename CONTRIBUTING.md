# Contributing

Read AGENTS.md and docs/continuation.md first. The next phase is complete design review; application implementation requires Aymen's explicit authorization.

Use a short-lived branch and pull request to main. Follow English Conventional Commits without emoji or attribution trailers, preserve French product copy and use synthetic data only. Read the current relevant requirements/rules/UX/architecture/data/API/test documents before changing a story. Record assumptions and source versions.

Run the documentation checks described in docs/agent-setup.md and the current workflow. Do not add fake application builds, badges or coverage results. Supply actual functional/visual evidence for the change. Do not copy professional configuration or disclose credentials. Required third-party licenses must remain intact.

There is no application-wide open-source license selected yet. Public visibility is not a substitute for a license grant; third-party licenses continue to apply.
