# Security policy

Étaye is currently a synthetic-data portfolio project in planning and design. It is not ready for real patient information. Do not submit real medical data or credentials in issues, screenshots or reports.

Report a suspected vulnerability privately through the repository's Security → Report a vulnerability flow when available. Include the affected commit, synthetic reproduction, expected/actual behavior and impact. Do not disclose a live secret in a public issue. If private reporting is unavailable, request a private contact route from the maintainer without posting exploit details or sensitive data publicly.

The maintainer reviews reports on a best-effort basis; no support SLA or certification is claimed. Current evidence and limitations are recorded in docs/review-report.md and docs/operations/github-security.md. Only the current main planning/tooling revision is maintained during this phase.
